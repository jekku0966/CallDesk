CallDeck

Connection settings are shared by all CallDeck buttons.

Use the same 64-character token as the Vencord CallDeck plugin. Never use your Discord account token.

Supports Standard/MK.2, Mini, XL, + and Neo. Uses a separate bundled profile with Answer, Decline, Hang Up and Back; cannot jump to page 2 of your own profile. Import the matching profile before enabling. Monitoring stays active while your keys are hidden.

Leaving the bundled controls cancels automatic return. The SDK cannot report every manual layout change. Choose manual return if you need full control. Calls already ringing at startup/reconnect do not trigger a switch.

Connecting to Stream Deck…

Save your device selection, then open the call profile once and accept installation if prompted. Press its Back key to return. Do this before relying on incoming-call switching.

Idle: static dim icons. Incoming call: Answer shows the caller; Decline rattles. Connected: Answer shows call status and Hang Up lights up. Clicks are ignored when no suitable call exists.
