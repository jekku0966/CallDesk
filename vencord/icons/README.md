# CallDeck Stream Deck icons

Three 144 × 144 PNG icons and three looping GIF icons.

- Answer: handset rattle; ringing arcs stay fixed.
- Decline: handset rattle; X stays fixed.
- Hang Up: contracting connection trails.

In Stream Deck, select your HTTP action, open its icon menu, choose Set from File, and select the matching PNG or GIF. If your action/plugin does not display animated GIFs, use the PNG.

These images do not automatically track Discord call state. Configure state-dependent icons separately if your HTTP action supports them. Animations loop while assigned, including when no call is ringing.

Artwork generated with OpenAI image generation; animation assembled with Pillow. Included under this package's GPL-3.0-or-later license. No Discord or Elgato endorsement implied.
